## §1 立案（主 agent）

### 1.1 目标（一句话）

让桌宠**反映 DSH 会话的真实工作状态**——回合开始（思考）/ 工具调用（忙碌）/ 工具完成（整理）/ 等待批准（等待）/ 回合成功结束（庆祝，失败则垂头叹气）时，切到对应档位的动画，并（可选）弹一条状态气泡。

### 1.2 范围（做 / 不做）

**做**：
- 五至六档**工作状态档位**的**动画映射**（走 B18 已建成的池机制：新增 `events.workStatus.*` 或独立 `workStatus` 段）。
- **会话事件 → 状态档位**的触发链（读面复用 B09 已落成的会话记录读取面，见 1.3）。
- 状态**气泡文本**（可选、按档位；默认关闭或按裁定）。
- **状态回退**：状态档位结束后按既有链规则回自然档（沿用 B18 的三级回落与 1.6 定时器口径）。
- 开关面（用户可关；默认值由 1.6 待决项裁定）。

**不做（本批出批）**：
- 余额档位气泡 / 碎碎念 / 对话 / 记忆持久化（**D2 面**）。
- 物理手感 / 位移接管（**B 面**，含 O10 裁定）。
- 多实例 / pet pack（**E 面**）；素材生产链（**C 面**）。
- **不改**：`shell-pet-geometry.js` / `shell-pet-drag.js`（几何冻结面）· `assets/pet-anim/webm/**` 素材本体 · B18 的双缓冲形态与池校验 V1–V6 · B09 的完成提醒判定门（只读复用其读面）。

### 1.4 硬约束（不得偏离）

1. **几何层零 diff**：`shell-pet-geometry.js` / `shell-pet-drag.js` 不得出现在 `git diff`（承 B18 同款硬门禁）。
2. **素材本体只读**：`assets/pet-anim/webm/**` 不得增删改；本批只**引用**（池数据面）。
3. **PNG 通道零回退**：视频不可用时的三级回落与既有 PNG 动画语义不变。
4. **零新依赖**：不引入 npm 包、不改 `dependencies`；新增渲染档（若有）须同步 `build.files`。
5. **默认行为保守**：状态联动对既有用户的默认影响必须显式裁定（**默认关**或**默认开**，见 1.6）。
6. **行宽 ≤300（不含行尾 CR）· 代码档 ≤500 行 · 文件头标准形**（`docs/CONVENTIONS.md` §一 / §五）。
7. **许可面沿用 B18 结论**：素材禁商用（用户裁定本仓不商用 + 商用化消解路径），署名三处已在位，本批**不得移除或改写**署名。
