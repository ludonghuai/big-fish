# B28 —— 插件面小修（用户可见缺陷三处）

## §1 立案（主 agent）

### 1.1 目标（一句话）

修掉插件 / 后端面三处「点了没反应或假成功」的缺陷：一键安装不可达 · 卸载 `builtin:` 假成功 · 旧后端进程清理对 Windows 不生效。

### 1.2 任务来源

台账技术待办（均已实测、非本批引入、用户可见或静默失效）：**T22**（一键安装死码）· **T32**（卸载假成功）· **T30**（进程清理通配不匹配）；顺带 **T23**（插件市场面同族两项低风险卫生）。用户 2026-09-19「该立项的赶紧立项」。

### 1.3 现状实测（证据，as-of 2026-09-19）

- **T22**：`market.js:99-103` 的 `normalizePlugin` 只从 `install` 字段提 `add …` 形态，而内置条目 `install` = 字面量 `builtin:<name>` ⇒ `installSpec === undefined` ⇒ `market.js:275` 的「一键安装」为**死码** ✗（对照：`shell-plugins.js` 的 `builtin:` 分支**已实现** ✓）。
- **T32**：`shell-plugins.js:412` / `:415` / `:421` / `:424` 卸载动作面用**原始入参** ⇒ `uninstallPlugin('builtin:<名>')` 返回 `{ok:true, '已卸载 builtin:<名>…'}` 而**实际未删未注销** ✗（B12 交付报告 §5.6 残余 #4，主 agent 亲验）。
- **T30**：`scripts/ensure-deps.js` 的 PowerShell 清理通配对反斜杠路径不匹配 ⇒ 用户运行中的旧后端**未被清**（B08 §5.6 范围外注记实测）⇒ 依赖变更后旧后端可能仍占端口 / 跑旧代码。
- **T23**：`market.js` 两项低风险卫生（细节 = 台账 T23 行）。

### 1.4 范围（做 / 不做）

**做**：① T22（让「一键安装」走通 **或** 移除死码 —— 见 U-1）；② T32（动作面改用 `resolveInstalledName` 的解析结果）；③ T30（清理通配修正）；④ T23 两项。
**不做**：① **不夹带重构**（台账 T39 / T42 原文警示：不得在修复轮夹带 ✗）；② 不改插件面其它口径（B12 已收口面逐字不回退 ✗）；③ 不动 T18 / T19 / T20（已收口 ✓）。

### 1.5 硬约束

1. **行为修正须留取证行**（T42 家族教训：早退 / 异常分支在 debug 开关下至少一行）。
2. 每处修复 = **最小改动**；B12 已锁定守卫面（三形态白名单门 / 节点构造 / 单次快照）逐字不动。
3. 三道门 + lint；B12 写域冻结面机检零 diff。

### 1.6 待决项（须裁定后才能定稿设计）

- **U-1**：T22 修复方向——**A 补可达路径**（`normalizePlugin` 认 `builtin:` 形态 ⇒ 一键安装走通；保留用户可见能力）vs **B 移除死码**（UI 去掉该按钮）——推荐 **A**（最终由用户裁）。
- **U-2**：T30 是否同轮（跨面：脚本层 vs 插件层）——推荐同轮（同属「静默失效」家族）。

### 1.7 关联台账与需求档

台账 **T22 / T23 / T30 / T32** → 本批（销账条件 = 修复 + 机检 + 用户实机确认）；需求档：无新增（缺陷修复；行为口径以 B12 已收口面为准）。

### 1.8 交付物与排期

交付物 = 四处修复 + 行为面取证（before / after）+ 本档六段。**零在途冲突**（`shell-plugins.js` / `market.js` / `scripts/ensure-deps.js` 无在飞写者）⇒ 可立即派设计。
