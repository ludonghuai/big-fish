# B35 批次档 —— 右键弹窗重做与动作图鉴卡片化：窗口形态 / 视频卡墙 / 喜欢与屏蔽 / Lv.10 特权

> 六段制 · append-only · 一段一作者：§1 主 agent / §2 eng-designer / §3 设计评审 / §4 主 agent / §5 eng-coder / §6 主 agent。
> 本档 = **本仓原创需求**（非移植面）——台账 **R24**；承 B23 的门控与图鉴数据面（`pet-unlock-core.js` / `unlock:view`）。
> 用户 2026-09-20 原话：「右键喂养与动作图签做的太烂了，弹窗大小调整不了，整个布局丝毫没有精心设计过；帮我把布局调整的好看一点，UI 做好；
> 动作图签做的高级一点；加一个用户屏蔽和喜欢的动作，允许用户设定喜欢的动作组合或者屏蔽某个动作，都在动作图签里面完成；总览界面要好看，

> 无视时间限制，自由组合。」

## §1 立案（主 agent）

### 1.1 目标（一句话）

把右键弹窗从「320×500 固定小窗 + 纯文字清单」重做为一扇**可调整大小、精心设计**的桌宠面板：喂养面布局重排、图鉴升级为**视频卡片墙**
（每动作一张卡、可喜欢 / 可屏蔽、有收集感），满级（Lv.10）玩家获得**无视时间限制**的自由特权。

### 1.2 范围（做 / 不做）

**做**：

- **窗口形态**：`resizable` 放开 + 最小 / 默认尺寸 + 尺寸持久化（重启记住）+ 贴宠弹出位置逻辑适配可变尺寸。
- **喂养面布局重做**：分区与视觉层级重排（余额 / 好感头部卡 + 食物卡片化列表），与图鉴面同一套视觉语言。
- **图鉴面重做 = 视频卡片墙**：网格卡片；每卡 = 对应 webm 视频（可见即播 / 离屏即停 / 懒加载）+ 动作名 + 解锁条件 + 状态徽标 + 喜欢 / 屏蔽按钮；总览头部 = 收集进度。
- **喜欢体系**：星标收藏 + 选中权重提升（更常出现）+ 收藏组置顶 + 「只看喜欢」开关（用户裁定 D-2）。
- **屏蔽体系**：全屏蔽——随机轮换池与事件触发（喂食联动 / 点击回应等）均不再出现（用户裁定 D-3）；**独占事件唯一段不可屏蔽**（UI 明示原因）。
- **Lv.10 特权**：等级 ≥ 10 ⇒ 时节门 / 饭点门的**时间窗口**与「一天一次」全部解除（用户裁定 D-4），节日与三餐动作随时可演、可入喜欢组合。
- **持久化**：喜欢 / 屏蔽集合与窗口尺寸落盘（`userData`），重启保留。

**不做（本批出批）**：

- 抽卡 / 成就 / 任务系统 · 多宠物 · 云同步 · 用户面动作导入（归 B24 后置）。
- **不改素材本体**：`assets/pet-anim/webm/**` 零增删改（视频卡直接复用既有段，零新素材——裁定 D-1 的代价面）。
- 不改 B23 三把锁对 **Lv.1–Lv.9** 的语义（特权仅挂 Lv.10；未满级用户逐位一致）。
- 卡片静态封面抽帧（已裁 = 视频卡，ffmpeg 抽帧方案出局）。
- 主窗口 / 市场 / 更新面 UI；托盘菜单结构（图鉴入口仍 = 右键弹窗内标签卡）。

### 1.4 硬约束（不得偏离）

1. **几何层零 diff**：`shell-pet-geometry.js` / `shell-pet-drag.js` 不得出现在 `git diff`。
2. **素材本体只读**：`assets/pet-anim/webm/**` 零增删改；`pool.json` 段名 / 分类 / 事件结构不改（喜欢权重 = 选择期倍率，不落池档）。
3. **屏蔽 = 硬排除**（口径承 B23）：被屏蔽段在运行期 `pick=` 行零出现（机检面），**不是**权重调零。
4. **独占事件段保护**：某事件的全部段被屏蔽 ⇒ 该事件回落行为须显式定义（设计档给出）；独占单段事件（drag / escape / quiet）的段在 UI 标「不可屏蔽」。
5. **Lv.1–Lv.9 逐位一致**：特权只挂 `level ≥ 10`；未满级的门控语义与 B23 交付态逐位一致（桩测断言面）。
6. **性能面**：视频卡**懒加载**（离屏不解码不播放）+ 同时播放数设上限；窗口为桌面常驻应用弹窗，不得引入可感知卡顿（设计档给上限值与桩测断言）。
7. **零新依赖** + 新增档登记 `build.files` + 行宽 ≤300 / 代码档 ≤500 / 文件头标准形 + 注释中文。
8. **三道门禁全绿**：`npm run lint` → `test:full` → `test:integration`（B16 门禁面）；既有 45 单元 + 3 集成场景零回退。
9. **CSP 与桥面最小化**：`exchange.html` CSP 改动与 `exchange-preload.js` 新增键逐一枚举进设计档受影响清单（先例 = B23 #3 的「桥键在场」判据）。
10. **许可面沿用 B18**（素材禁商用 + 署名在位，不得改写）；视频卡展示形态不产生新许可面（同包同素材）。
