# B22 —— 工作状态六档（事件桥）

## §1 立案（主 agent）

### 1.1 目标（一句话）

把桌宠工作状态从**可观测三档**（生成 / 工具 / 收尾，B19 已交付）扩到**六档**——补上「等待批准 / 回合成功 / 回合失败」，让用户直接从桌宠看出「在等你确认 / 干完了 / 失败了」。

### 1.2 任务来源

台账需求点 **R17**（用户 2026-09-18 裁定「做6种」；来源 = B19 交付后用户对照 `samples/dsh-pet` 六档样本提出）。B19 已预留扩展面（池段可增 3 键 + 判定门可扩档 ⇒ **增量补齐、不返工**；素材已在仓、未引用）。

### 1.3 现状实测（证据，as-of 2026-09-19）

- 「等待批准 / 回合成功 / 回合失败」的事件名存于 `dsh-agent-presets` 的 `SessionEventMap`；`dsh-user-approval` **明写 log-only** ⇒ **不进投影行** ⇒ 现只读落盘面**不可观测** ✗（B19 段实测）。
- B19 三档已收口（`shell-pet-work.js` / `pet-work-core.js` / 池三键 ✓）——扩展面 = **事件桥** + 池再增 3 键 + 判定门扩档。
- 台账：`docs/TODO.md` R17 行（上文证据即其摘要）。

### 1.4 范围（做 / 不做）

**做**：① **事件桥**（后端订阅 `turn/end` / `tool/call` / `approval` / `asked` 并落**本仓可控的**可读面——形态由设计定，先预研）；② 池增 3 键（素材已在仓、未引用）；③ 判定门扩档（B19 预留面）增量；④ 桌面表现与托盘可见性对齐既有三档口径。
**不做**：① 不改 B19 已收口三档口径 ✗；② 不动 `DSH_HOME` 的**写面**（只读口径不破 ✗）；③ 不新增 / 不改素材本体；④ 不夹带其它工作状态面（睡眠 / 散步面归其自有批次）。

### 1.5 硬约束

1. **增量补齐、不返工**（B19 的 AC / 池契约 / 判定门逐字不动，只扩展）。
2. 只读口径：本仓对 `DSH_HOME` **只读**（B19 先例）；事件桥的落盘面写在**本仓可控**位置。
3. 常量 / 键名单点；B19 已交付面机检零 diff；池契约（V1–V6）不破。
4. 三道门 + lint；素材许可面照 B18 先例。

### 1.6 待决项（须裁定后才能定稿设计）

- **U-1**：**事件桥实现面**（后端插件订阅 vs 本仓轮询 vs 其它）——设计者先做技术预研，再给候选 + 逐项理由（含只读口径与稳定性）。
- **U-2**：三新档的**优先级 / 让位规则**（相对 B19 三档、个人动作档、拖动档、静默期）。
- **U-3**：「等待批准」的**常驻时长口径**（一直保留到用户动作为止 vs 超时回落 —— 若超时，回落判据与时长）。

同族：T33（读面谓词重复——若同轮动该读面则一并核）。
