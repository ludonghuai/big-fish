### 1.4 范围（做 / 不做）

**做**：

1. **EOL 固化**（T24）：新增 `.gitattributes`，口径 = `* text=auto eol=lf`（与 `.editorconfig` 的 LF 声明同源）。
2. **散档归位**（T34）：8 档 `probe-*` + 5 档构建脚本归位到 **`scripts/`（已存在）或其子目录**；连带改：① 各档内部相对 `require` 的**深度** ② `probe-pet-media.js` → `main.js` 的硬绑（T29） ③ 各档**文件头的设计档指针**（R11 ② 的「未入档」由此一并解决）。
3. **垃圾清点**（T35）：`测试-更新功能/` 清点后三选一 → **删 / 归位 `tests/` / 归档**（在 §2 写明选择与依据）。
4. **迁移后机械守卫**（防回潮）：① `build.files` **仍为零 probe 条目** ② 全仓 `require` 面**零残留**（旧路径 grep = 0 命中）③ `npm start` 能起、既有桩测全绿。

**不做**：

- **不搬 `build.files` 内那 43 档**（T36 立场）：搬迁需连带改 43 条白名单 + 全部相对 require + 预载/渲染页路径 + `__dirname` 假设 ⇒ **收益仅观感、风险是发版面** ⇒ 本仓**接受「根目录平铺」**这一形态。
- **不改任何运行时行为**；**不改依赖**；**不删任何被引用的档**。
- **不做文档搬迁**（文档体系落点归其地图，D4 指针纪律）；**不写架构文档**（→ **B25**）。

### 1.5 硬约束（不得偏离）

1. **零行为变更**（纯位置 / 元数据）：判据 = 应用能起（`npm start`）+ 既有桩测全绿 + 项目门禁（lint → test:full → test:integration，就位后）全绿。
2. **不动 43 档白名单面**：`build.files` 的**条目集合**在本批前后逐条相同（顺序可变，集合不可变）。
3. **每次移动 = 全量核对**：移动后逐档 grep 旧路径（引用面 = 0 命中）；被移动档的相对引用深度全部修正。
4. **`.gitattributes` 只声明不「批量重写」**：本批只**声明口径**；如需重归一化（`git add --renormalize`）⇒ 单独列为一步并**事先报告**（可能产生大 diff）。
5. **零删除风险**：删除类动作（T35 若选「删」）须**先报告 + 用户确认**（不可逆）。
6. **行宽 ≤300 / 单档 ≤500 / 文件头标准形**（`docs/CONVENTIONS.md`）。
7. **排期**：**B19 / B20 实施交付之后**（两批在飞时移动文件 = 让它们的验收面全部失真）。
