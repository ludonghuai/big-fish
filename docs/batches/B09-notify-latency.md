# B09 —— 任务完成提醒的及时性

> 六段制批次档（每段一位作者、append-only）：§1 主 agent · §2 eng-designer · §3 评审子代理 · §4 主 agent · §5 eng-coder · §6 主 agent。

## §1 批次立案（主 agent）

### 1.1 立案背景

「Bigfish 任务已完成」提醒**迟滞太久**：用户体感为「早就做完了结果才发消息」。机制（主 agent 读码核实）：

- 判据 = **末次写入后空闲 `IDLE_NOTIFY_MS`**（`main.js:49` `30 * 1000`）⇒ 提醒时刻 = 末次写入 + 30 s（另有 5 s 周期定时器，实测落在 30–35 s）；
- 忙信号 = `~/.dsh` 下**非** `profiles/` · `node_modules` 的写入（`shell-notify.js` `isIgnoredPath`）——**与「真实完成」无因果**，只是「最近有没有磁盘活动」。

⇒ 提醒时刻与真实完成时刻**脱钩**，且固定多出 30 s。

### 1.2 任务来源

- 用户 2026-09-17 真机验收原话：「**通知间隔的时间太长了，早就做完了结果才发消息**」。
- 台账需求池 **R10**（本批承载）。
- **注意**：B07 的需求条目 US-11 明文锁定「通知文案 / 阈值（`IDLE_NOTIFY_MS = 30 s`）/ 托盘开关语义**不改**」⇒ 本项属**新需求点**，本批为独立批次，不改 B07 已核销的任何判据。

### 1.3 前置事实（主 agent 2026-09-17 实测，供设计直接引用）

| # | 事实 | 证据 |
|---|---|---|
| ① | **忙信号有效**（不必换信号源）：`~/.dsh/sessions/` 与 `~/.dsh/storages/` 在任务期间持续写入，且都不在忽略面内 | 2026-09-17 11:37 实测两目录 mtime 持续更新；`shell-notify.js:44-54`（`isIgnoredPath` 只忽略 `profiles` / `node_modules`） |
| ② | **「从后端输出识别回合结束」当前不可行**：后端启动后**不再输出任何行**（最后两次启动之间仅两行） | `%APPDATA%\bigfish\bigfish.log` 全档比对（`start backend` 行之间无其他输出） |
| ③ | 方向 = **缩短空闲阈值**（30 s → 8 s 量级），取值与误报边界由设计定 | 主 agent 2026-09-17 定向（用户已授权主 agent 定方向）；R10 台账行 |
| ④ | 钉版 `0.1.0-rc.6` 与活跃 `0.1.5-rc.1` 的后端行为差异不影响本批（本批只看 `~/.dsh` 写入面） | B08 §1.3 |

### 1.4 范围（含边界）

**做**：`shell-notify.js` 的**空闲阈值与判定**（可含 `main.js` 的常量注入）；阈值取值依据（误报边界）写成可验收判据。

**不做（边界）**：

- 不改通知**文案**、不改**托盘开关语义**、不改「关闭⇒重开不补发」语义、不改回落/`fs.watch` 机制（B07 已核销面**不动**）；
- 不引入 harness 侧改动（② 已排除：需改 harness ⇒ 出批）；
- 不新增依赖、不新增文件。

### 1.5 待决点（交给设计）

- **取值**：8 s 的中心值？还是「短阈值 + 二次判定」？——须给出**误报边界**：任务中途的静默窗口（如长工具调用、等待模型）不得触发「已完成」提醒；设计需说明在何种活动模式下会误报、以及如何界定可接受。
- **可配性**：是否随 env 暴露（B07 已有 `BIGFISH_WEB_URL_WAIT_MS` 先例，测试钩子口径）。
- **`notifyOnComplete` 关闭态**与阈值变更的交互（不得回退既有语义）。

### 1.6 验收标准（初拟，供设计细化并回指需求条目）

| # | 验收标准（可机检 / 可真机） |
|---|---|
| AC1 | 新阈值生效且可由测试钩子观测（取值以设计为准，须写明默认值与边界） |
| AC2 | **误报边界**：忙碌期内的静默窗口不产生「已完成」提醒（设计给出的判据可机检或桩测） |
| AC3 | 通知语义**不回退**：一个活动周期一次提醒 · 开关关闭⇒零提醒 · 关闭期活动⇒重开不补发 · 回落路径同语义 |
| AC4 | 真机体感：任务完成后**显著更快**收到提醒（用户判；须给出可对照的量化口径，如「末次写入 → 提醒」的实测区间） |
