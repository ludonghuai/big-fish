### 2.8 父侧落档项（`CHANGELOG.md` 起步 —— 本体由主 agent 落；本设计者不写该档）

- **与 `版本说明.txt` 的分工**（D2 防双维护）：`CHANGELOG.md` = **仓库面全量权威源**（开发者语汇）；`版本说明.txt` = **其派生摘要**（用户语汇 + 安装包清单 + 下载地址；读者见 `README.md:139-142`）。方向单一：**CHANGELOG → 版本说明**；不得反向回填。
- **建议起步内容形态**（骨架；日期与条目细节由主 agent 定）：
  1. `# Changelog` + 体例说明一行（Keep a Changelog + SemVer + 条目带批次档指针）。
  2. `## [Unreleased]`（空节，容纳本批之后的新变更）。
  3. `## [0.0.1]`（首次发布版；日期按发布记录填——台账 T11 记「release 待用户建」）：
     - `Added`：插件市场（搜索 / 分类 / 一键装卸 / 离线目录 + 断网兜底） · 鲸鱼娘桌宠升级（11 动作分帧 + 好感度 + 兑换屋） · 专注模式 / 鲸鱼模式。
     - `Fixed`：插件禁用启用不生效 · 后端启动失败崩溃改引导重置 · 重启打不开（残留进程清理 + 重试） · 桌宠散步不停与尺寸漂移 · 兑换屋「有钱但买不了」 · 更新检查增 jsdelivr 镜像。
  4. **首批条目口径** = **版本级**（对齐 `package.json:3` 的 `0.0.1`），粒度 = 一条用户可感变更一行；素材源 = 既有 `版本说明.txt`「一、本期核心 / 二、稳定性修复」（**一次性回溯种子**，此后按批/按版登记）；**不回溯逐次提交**（12 次提交不做逐条映射）。
- 维护时点建议：批次收口（§6 核销）时由主 agent 追加条目；发版时由 `CHANGELOG.md` 摘要出 `版本说明.txt`。
