**不做（边界）**：

- **不改任何业务代码**（本批零 `.js` 改动）；
- **不整仓格式化**（若引入 formatter，格式化本体**另批**执行，且**单独提交**）——接手项目的 blame 是稀缺资产；
- 不建测试门 / 不接 CI（= **B16**，本批只写目标与指针）；
- **不动 `docs/README.md`**（文档地图 = 主 agent 写域；设计者只**提出建议行**，由主 agent 落）；
- 不改 `docs/requirements|design` 既有内容与批次档既有段落。
