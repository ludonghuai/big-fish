### 1.3 本批范围

**做**：
1. **动画池抽象**：动作 → 片段数组（可多段）+ 权重链（idle / turn / move + 分类权重）+ 播完即按权重选下一个、首尾相接；
2. **双缓冲交叉淡入**：切换无空白帧（两个渲染位交替 + 淡入）；
3. **事件档位动画**：`events.<name>` = 候选数组（触发时档内随机、循环自动轮换，避免连播同一段）；
4. **素材接入**：接入样本的 webm 池（**采用范围待用户定**，见 §1.6）——播放器需支持 **VP9-alpha webm**；**保留现有 PNG 逐帧通道**（向后兼容，池可为空时回落）；
5. **无障碍**：`prefers-reduced-motion` ⇒ 跳过我方新引入的交叉淡入与既有 CSS 动效（**本批新立**——实测全仓该媒体查询**零命中**，故非「对齐既有规范」；本仓亦无挤压动效，那属 B 面）。

**不做（边界）**：
- 不改 `shell-pet-geometry.js`（**几何层冻结**——B03 十三轮修正成果，见 §1.4）；
- 不做物理手感（甩抛/抛物线/反弹/挤压）= **B 面**；
- 不做会话事件联动 / 余额 / 碎碎念 / 对话 = **D1 / D2 面**；
- 不做多实例 / pet pack = **E 面**；不做素材生成链 = **C 面**；
- 不引入 TS / React / cordis / tsdown / 新构建链（本仓 = CJS + Electron；B11 规范：不引入 lint/构建大改）；
- 不采用其 DSH 插件架构与 Electron 运行时下载（本仓是**宿主应用**、随包发）。

### 5.5 发现与偏差上报（逐条 · 实施者自报）

1. **🔴 AC3 的「≥60 次 / 10 min」在「完整应用 + 无人干预」形态下不可达**（判据面缺陷，须设计/需求层裁定）：

   - 原因 ②：既有「2 min 空闲 ⇒ `sleep`」规则（US-17 边界明写「不改既有触发时机与阈值」）在 2 min 处把链推入 `sleep` 循环段（`loop=1` ⇒ 无 `ended` ⇒ 链停止换段）⇒ 真实应用 10 min 实测仅 **19** 次 `anim switch`；
