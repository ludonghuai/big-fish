        Bigfish 使用说明
   DeepSeek Harness 第三方桌面端
   （非官方，独立社区项目，免费）
   v0.0.1 · Windows 10 / 11
══════════════════════════════════════

【一、下载】
  下载最新版安装包  Bigfish.Setup.0.0.1.exe（约 276 MB）：
  https://github.com/ludonghuai/big-fish/releases
  · 安装包体积超过 Gitee 发行版附件的 100 MB 上限，所以托管在 GitHub Releases
  · 如果链接打不开（GitHub 在国内部分网络下不稳定），换个网络或用加速工具再试
  · 下载时认准文件名 Bigfish.Setup.0.0.1.exe（点分隔），别下到旧版

【二、安装】
  1. 双击 exe，按向导安装（安装包较大，需要几分钟，属正常，别关）
  2. 如果 Windows 弹出蓝色警告「Windows 已保护你的电脑」：
     点「更多信息」→「仍要运行」
     （说明：软件还没买代码签名，不是病毒）

【三、首次使用】
  1. 桌面会出现「Bigfish」图标，双击打开
  2. 新手向导会带你去 DeepSeek 官网：
     注册/登录 → 充值（新用户有免费额度）→ 创建 API Key
  3. 把 Key 填到软件的「设置 → 模型」里，保存即可

【四、常用功能】
  · 说一句话，让它帮你做 PPT、总结文档、写文案、翻译
  · 桌面萌宠（鲸鱼娘）：可拖动、点击互动、随机散步/睡觉/说话
  · 任务跑完它会冒泡提醒你
  · Ctrl+Shift+D 随时唤起/隐藏主窗口

【五、插件市场】
  1. 右下角托盘图标 → 右键 →「插件市场」
  2. 连接社区最大插件平台（awesome-dsh-plugin，1000+ 插件），
     支持搜索、按分类浏览：桌宠 / 趣味 / 效率 / 界面 / 开发 …
  3. 点「安装」→ 确认 → 安装完成后点「立即重启」即可生效
  4. 装好的插件会出现在 DSH 的「设置」页里（每个插件有自己的设置卡）
  5. 想卸载：在插件市场里点「卸载」→ 重启即可
  · 需要联网下载插件（第一次装可能要等几分钟，属正常）

【六、说明】
  · 这是第三方独立项目，不是 DeepSeek 官方出品
  · 所有数据只存在你自己电脑本地，不收集任何个人信息
  · API Key 只保存在本地，不会上传给第三方
  · 插件市场目录来自社区平台 awesome-dsh-plugin.com，各插件版权归作者所有
